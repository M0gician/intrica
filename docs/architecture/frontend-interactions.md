# 前端交互实现

本文说明 Web 与 Electron 共用前端的模块职责、数据一致性规则和验证范围。交互实现采用 React、连接范围内的数据服务、可见区域渲染和浏览器原生模态能力。

## 模块职责

| 目录 | 职责 |
| --- | --- |
| `apps/web/src/app` | 服务连接、登录、绑定生命周期 |
| `apps/web/src/data/graph` | 图提交合并、快照与事件同步、按领域组织的命令 |
| `apps/web/src/data/activity.ts` | 画布、Agent、会话、审批的定向刷新与请求合并 |
| `apps/web/src/state` | 已确认图数据与独立的交互状态 |
| `apps/web/src/features/canvas` | 场景投影、几何、可见性、手势、选择与节点呈现 |
| `apps/web/src/features/conversations` | 会话数据、运行事件、编辑草稿、时间线和协作消息 |
| `apps/web/src/features/settings` | 设置导航、草稿确认和具体设置表单 |
| `apps/web/src/ui` | 按钮、表单控件、原生模态框、反馈与错误边界 |

`App`、`Canvas` 和 controller 负责装配。节点壳、内容呈现、资源描述、会话读取和表单编辑各自独立。样式按功能组织，控件通过显式 class 与 variant 表达用途。依赖检查禁止 UI 基础组件导入业务层，也禁止数据层反向导入功能组件。

## 图数据与命令

HTTP 命令回执和画布事件携带同一份 `GraphDelta`，包含画布、图版本、命令与请求 ID、节点和边的变化，以及生成批次元数据。连接检查 `GRAPH_PROTOCOL`，客户端与服务端使用相同协议。

客户端按画布图版本连续应用提交。快照加载期间收到的提交先排队；安装快照后，确认已包含的提交，再应用后续版本。正文读取只补充内容，不改变位置、排序或父子关系。连接代次限制异步响应的有效范围，正文版本变化会触发相应的新读取。

拖动预览单独存储，通过投影显示，不写入已确认节点。命令确认或失败时结束相应预览；切换画布结束该画布的界面预览。撤销提示绑定具体命令，快捷键历史按提交版本排序。子树复制由服务端单事务完成，具有一个回执和一个撤销目标；复制的 Agent 处于停止状态。

节点的 `canvasId`、`layoutVersion`、`sortKey`、`contentLoaded`，以及快照的 `activeCanvasId`、`canvasSeq` 是必需字段。数据库中的画布独立存储；当前渲染协议使用画布根投影与节点共同表达作用域。

## 交互与性能

单击选择节点，双击或显式详情操作打开内容。多选保持工作区工具导航。新建可编辑节点直接进入编辑；异步创建完成后，仅在原画布仍然活跃时更新选择和详情。

手势只接受发起它的 pointer ID。移动采样按动画帧合并，松开时提交最后一个采样；失焦、Escape 和 pointer cancel 结束手势。可见节点按稳定的场景顺序渲染，选中数量不决定挂载数量。几何变化按访问计算，边的拓扑投影独立缓存。

节点呈现定义统一声明是否允许从正文区域开始移动。图片与 PDF 的整个预览区域可拖动，包括上传附件、服务器文件、发布快照及加载中或失败的占位。文字、目录、网页、容器和待办通过标题栏移动；Agent 通过肖像卡片区域移动，按钮保留自身操作。图片、网页预览和上传的 Agent 肖像禁用浏览器原生图片拖放，避免中断节点移动或被重新导入。指针移动超过 8 个屏幕像素后开始节点拖动；更小的移动只参与点击选择。所有入口共用缩放换算、取消、跨层级校验与位置提交。

会话刷新按连接和具体对象订阅。隐藏面板停止读取和运行事件展示，服务端任务继续执行；重新打开时读取当前状态。流式文本直接更新当前回复，持久消息以服务端快照为准。事件游标失效时，先取得权威游标，再建立对应运行的订阅。

设置使用应用级页面，运行用量与其他设置共用导航。React `Activity` 保留隐藏画布的状态和 DOM，并停用界面 Effects；服务器连接继续接收图更新。返回画布后恢复界面订阅。设置页面统一处理 URL、搜索、字段定位与草稿确认。

对象编辑和确认由 `HTMLDialogElement.showModal()` 提供顶层展示、背景不可交互和焦点管理。关闭时在元素仍连接到文档的阶段结束原生模态生命周期，以恢复触发控件的焦点。Electron 原生浏览器视图根据当前页面与模态计数暂停展示。

## 会话导航

Agent 共享会话、模型会话和协作消息页共用 `features/conversations/navigation`。单个会话按持久记录序号定位；协作消息页使用“会话 ID + 消息序号”，按创建时间、会话 ID、序号排序，避免不同 Agent 的同序号记录冲突。用户输入、协作入站、资源或定时触发、报告、团队通知和交接记录均可定位；失败、工具结果未知及达到回合上限也有锚点。普通工具输出、助手回复和正常结束状态沿用所属锚点。

导航沿用 Intrica 的主题颜色和共享控件。

| 部分 | 实现契约 |
| --- | --- |
| 显示条件 | 至少一个锚点，会话区域宽度至少 440 px，且正文可滚动或存在未加载的历史页 |
| 刻度 | 位于正文右侧，与滚动条内侧保持 12 px 间距；右边缘固定并向左伸展，行高 10 px；通常宽 6 px，悬停宽 26 px，相邻三级宽 20、14、10 px |
| 可见位置 | `IntersectionObserver` 将可见正文映射到相应锚点，允许多个刻度同时标记 |
| 预览 | 从刻度左侧弹出，320 px 宽，8 px 内边距，14 px 字号；输入标题单行省略，回复节选最多三行；协作消息显示参与者和消息节选；最多两个产出标签及剩余数量 |
| 内容读取 | 停留 150 ms 后读取已有正文节选；明确区分加载中、可用和不可用；已读取内容直接复用 |
| 点击与拖动 | 点击可读取目标历史页并定位；拖动只定位已挂载的目标，不读取沿途正文或预览 |
| 键盘 | Alt/Option + 上下箭头定位会话锚点；在回复中按上箭头先返回所属锚点，再到上一条；刻度支持方向键、Home、End；预览 Escape 返回对应刻度焦点 |
| 书签 | 保存于当前设备，按服务器和会话隔离；协作消息按服务器和画布隔离，切换团队筛选后保留；同浏览器标签页同步；存储失败显示错误 |

会话读取由 `ConversationReader` 负责，执行与写入由 `Conversations` 负责。`ConversationNavigation` 提供两个独立读取接口：

- `GET /api/v2/conversations/:id/navigation?after=...`：每页最多 512 个锚点序号、下一页游标及持久消息版本，不含正文。
- `GET /api/v2/conversations/:id/navigation/:seq`：返回 `kind`、`title`、`excerpt` 和产出标签；标题与节选各至多 240 字符。预览在同一个只读数据库快照中生成。

预览缓存复用进行中的请求与已完成结果。持久消息版本变化时刷新最后一个锚点的预览。预览中的链接和图片仅显示文本，不发起外部资源请求。

`CanvasMessages` 使用相同的团队和参与者条件读取协作正文、导航索引与预览。索引接口为 `GET /api/v2/canvas-activity/navigation`，单条预览使用 `/navigation/:key`；正文通过 `/api/v2/canvas-activity` 的 `before`、`after` 或 `around` 游标读取。索引每页最多 512 个标识，不含正文。协作索引在画布变化后重新读取轻量标识，覆盖时间较早但随后到达的消息。筛选变化会取消旧定位，旧请求不能覆盖当前页面。

单会话正文每页最多 80 条消息，协作正文每页最多 100 条；Agent 的当前流式回复独立更新。正文左侧留白为 20 px，导航显示时右侧留白为 64 px。导航、分页和返回最新内容共用一个滚动控制器，新导航会取消旧导航的提交资格。定位在目标正文挂载后执行，并短暂标记目标。模型会话查看历史时，最新会话数据继续更新；返回最新会话时切回该数据。

刻度按 64 项分组，局部悬停仅更新相关组。正文使用真实布局，`ResizeObserver` 处理跟随最新内容时的尺寸变化。导航呈现模块延迟加载；隐藏会话面板会停止导航订阅。减少动态效果偏好同时作用于刻度和定位滚动。
