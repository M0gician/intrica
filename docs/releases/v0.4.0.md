# Intrica v0.4.0

## English

This version improves team collaboration, artifact delivery and the readability of
Agent conversations. Desktop and Server are released together as **0.4.0**.

### Changes

- Collaboration messages track read and reply deadlines independently. Senders can
  defer reminders, prioritize an existing message or stop tracking it. Automatic
  collaboration starts enabled; pausing preserves pending inputs.
- Inbox review distinguishes dependencies that still require waiting from work
  ready for final delivery. Removed members leave durable unfinished-handoff notices.
- Published snapshot permissions authorize immutable bytes independently of source
  paths. Approval recovery stops when execution conditions are no longer satisfied,
  preventing repeated requests for one tool call.
- `grant_resources` delegates authorized resources atomically. `copy_artifact`
  verifies a published snapshot and copies it into the caller's own workspace for
  independent file or browser checks.
- Completed tool effects survive cancellation and cross-run recovery. Removing a
  managed Agent no longer stops its manager. Resource revocation preserves unread input.
- Tool errors carry actionable field diagnostics and accurate no-effect status.
  Agent status includes model phase, elapsed time and first/latest response activity.
- Read/unread and priority use compact icons. Agent identity appears in the
  collaboration bar when the profile scrolls out of view. Non-bubble timestamps
  follow the left-side summary and appear on hover or keyboard focus. All 28
  built-in tool names have English and Chinese UI labels.
- File references share preview/download behavior. HTML previews support scripts
  and WebGL in isolation, artifact content can be dragged, and workspace browsing
  starts at the canvas root. Sandbox networking and browser runtime discovery improve.
- SSH setup installs the matching server version with progress reporting. Desktop
  updates verify replacement and startup while preserving profiles and data.

### Upgrade

Stop active work and back up the complete data directory and database before
upgrading. Install matching Desktop and Server versions, then reconnect browsers.
The migration advances the database to **schema 16** and tools to **schema 5**.
Do not start an older server against the migrated database; restore a matching
backup for a rollback.

Results use `send_message` with `kind:"result"`; `report_result` has no execution
alias. Takeover deliveries use `handoffResourceIds`. Input access is granted with
`grant_resources`, separately from sending `fileIds`. Waiting requires a current
inbox review; prospective monitoring also requires a reason.

### Packages and verification

The release workflow builds macOS Apple Silicon DMG/ZIP, Linux x64 DEB/AppImage,
Linux x64 native server and the server container. Public download inventory,
SHA-256 checksums and the container digest are published in `intrica-update.json`
and `SHA256SUMS`. Download URLs are pinned to this release tag.

The macOS packages use **ad-hoc signing and are not notarized by Apple**. CI
verifies the complete code-signature resource seal and installed applications.
Install manually: quit Intrica, copy the new app to Applications, replace the
previous copy and reopen it. If macOS blocks startup, use System Settings →
Privacy & Security → Open Anyway. Automatic replacement still requires a trusted
signature; ad-hoc installations provide a manual download action. Follow [installation](https://github.com/M0gician/intrica/blob/v0.4.0/README.md),
[self-hosting](https://github.com/M0gician/intrica/blob/v0.4.0/docs/self-hosting.md) and [update/recovery](https://github.com/M0gician/intrica/blob/v0.4.0/docs/updating.md) instructions.

## 简体中文

本版改善团队协作、产物交接和 Agent 会话的可读性。桌面端与服务端版本统一为 **0.4.0**。

### 主要变化

- 协作消息分别跟踪未读和回复期限，支持延后提醒、加急原消息及停止跟踪。自动协作默认启用，暂停保留待处理输入。
- 信箱复核明确区分等待依赖和最终交付。成员移除后保留未完成交接事项，避免将成员退出视为任务完成。
- 发布快照与源路径分别授权；执行条件不再满足时终止原审批恢复，避免同一调用反复申请。
- 新增 `grant_resources` 原子委派资源，以及 `copy_artifact` 校验并复制获准快照到自身工作区，便于独立文件和浏览器检查。
- 跨运行恢复补回已完成工具的持久回执；移除成员不再误停管理员，真实资源撤权保留未读输入。
- 工具错误提供准确字段和未执行标记；Agent 状态包含模型阶段、耗时及首末响应时间。
- 已读、未读和加急采用图标；资料区域滚出视口后，协作栏显示当前 Agent 身份。非气泡时间在悬浮或键盘聚焦时跟随左侧摘要显示。28 个内置工具均提供中英文界面名称。
- 文件入口统一预览与下载，隔离 HTML 预览支持脚本和 WebGL，产物内容支持拖拽，文件浏览器默认定位画布根目录。改善沙箱网络与浏览器运行环境发现。
- SSH 安装自动选择匹配版本并显示进度，桌面更新验证替换和启动结果，保留配置与数据。

### 升级说明

升级前停止活动任务，完整备份数据目录及数据库。桌面端和服务端使用匹配版本，升级后重新连接浏览器。
数据库迁移至 **schema 16**，工具接口升级至 **schema 5**。回滚需恢复匹配备份，不要用旧服务端打开已迁移数据库。

结果通过 `send_message(kind:"result")` 提交，`report_result` 不再提供执行入口。
接管任务的交付字段为 `handoffResourceIds`；输入权限通过 `grant_resources` 授予，发送 `fileIds` 不隐式授权。
等待前必须完成当前信箱复核；无当前依赖的后续值守还需说明原因。

发布流程生成 macOS Apple Silicon、Linux x64 桌面安装包、Linux x64 原生服务包和服务端容器。
完整文件清单、校验值及镜像摘要随发布产物提供。**macOS 使用临时签名，未经 Apple 公证**；CI 校验代码签名的资源完整性和安装后的应用。
请退出 Intrica，将新版复制到“应用程序”并替换旧版，再重新打开。若 macOS 拦截启动，在“系统设置 → 隐私与安全性”中选择“仍要打开”。
自动替换继续要求可信签名；临时签名版本提供手动下载入口。
安装和升级步骤见[中文说明](https://github.com/M0gician/intrica/blob/v0.4.0/README.zh-CN.md)、[自托管](https://github.com/M0gician/intrica/blob/v0.4.0/docs/self-hosting.md)及[更新与恢复](https://github.com/M0gician/intrica/blob/v0.4.0/docs/updating.md)。
