# Intrica v0.5.2

## English

This patch fixes context compaction failures in long Agent conversations, especially
after consecutive file reads or command results. Desktop and Server are **0.5.2**.

### Fixes

- Split history only between complete assistant tool-call/result groups. A large
  final group can enter the summary source instead of keeping the entire history
  in the tail and sending an empty summarization request.
- Reject empty sources before contacting the model. Use the previous valid summary
  as evidence when generating its replacement.
- Assemble the original instructions, new summary and retained history in memory.
  Save only when the context is smaller and within the model budget, including
  the current prompt and tools. Failed or cancelled compaction preserves the
  checkpoint, valid summary, memory and compaction count.
- Preserve specific summary and budget failures. Three failed summary validations
  are reported as a validation limit, with English and Chinese explanations.
- Diagnostic events record source counts, token estimates and the failure stage.

### Upgrade

Database **schema 17** and tool **schema 6** are unchanged from 0.5.0/0.5.1.
Update Desktop and any separately deployed Server. After installing, send an
explicit continuation message to resume a failed conversation.

**macOS uses ad-hoc signing and is not notarized by Apple.** Quit Intrica and
manually replace the app in Applications. If startup is blocked, use System
Settings → Privacy & Security → Open Anyway.

Downloads include macOS Apple Silicon DMG/ZIP, Linux x64 DEB/AppImage, the Linux
x64 native server and a server container. The release provides `intrica-update.json`
and `SHA256SUMS` for the complete inventory and checksums.

## 简体中文

本补丁修复 Agent 长会话在连续读取文件或执行命令后出现的上下文整理失败。
桌面端与服务端版本统一为 **0.5.2**。

### 修复内容

- 按完整的工具调用及对应结果切分历史。末尾结果过大时，也可纳入摘要来源，避免保留全部历史却发送空摘要请求。
- 来源为空时直接说明原因，不请求模型；生成新摘要时保留旧有效摘要作为证据。
- 先在内存中组装真实指令、新摘要和保留历史，计入当前提示词与工具定义。只有内容确实缩小且低于上下文预算，才保存摘要、会话记录、资料及整理次数；失败或取消时保留原状态。
- 保留摘要和预算错误的具体原因，连续 3 次摘要校验失败时准确说明次数上限，并提供中英文提示。
- 诊断事件仅记录来源数、token 估算和失败阶段等元数据。

### 升级说明

数据库 **schema 17** 和工具 **schema 6** 与 0.5.0/0.5.1 相同。
更新桌面端以及单独部署的服务端后，可向已失败的会话发送明确的继续指令。

**macOS 使用临时签名，未经 Apple 公证，需要手动安装。** 请退出 Intrica，替换“应用程序”中的旧版。
若 macOS 拦截启动，在“系统设置 → 隐私与安全性”中选择“仍要打开”。

发布产物包含 macOS Apple Silicon 和 Linux x64 桌面安装包、Linux x64 原生服务包及服务端容器。
完整文件清单与校验值见 `intrica-update.json` 和 `SHA256SUMS`。
