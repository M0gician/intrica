# Intrica 0.3.0

This release provides the visual workspace, Agent collaboration, right-side
message navigation and public installation/update contract.

Desktop installers target macOS arm64 and Linux x64. The native server
targets Linux x64. Published packages include their runtime and Web client.
Public downloads require no GitHub account, personal token or GitHub CLI.

Before updating, stop active execution and back up the complete workspace.
Schema 8 and 9 databases migrate to schema 10; affected conversations pause
for outcome verification and explicit continuation. Unknown side effects
are not automatically retried. See [updates and recovery](../updating.md).

Desktop and remote server upgrades are independent. SSH deployment needs
a trusted host key, non-root Linux account, systemd user session, linger
and working Bubblewrap. Container users pin the published image digest.

macOS builds without configured Developer ID signing/notarization use an
ad-hoc signature and need explicit first-launch approval. Intrica supports
individual users and trusted teams, not isolated tenant accounts.
