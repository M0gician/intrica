# Intrica v0.5.0

## English

This version improves recovery and continuity during long collaborative runs.
Desktop and Server are released together as **0.5.0**.

### Changes

- Original instructions remain separate from generated context summaries. Structured
  summaries retain source references and checkpoints; stale compaction results cannot
  replace newer context.
- Agents review remaining work, message obligations and delivery evidence before
  waiting or ending. `read_inbox` and `review_progress` replace the previous inbox
  confirmation and waiting handshake. Message decisions use flat arguments.
- Model requests share durable endpoint quotas, fair admission, bounded retries and
  cooldowns. Successful responses are retained for recovery. Ordinary message
  reminders are consumed at a safe boundary without interrupting active inference.
- File reads use flat arguments and persistent cursors bound to their conversation
  and source version. Large UTF-8 files stream in bounded pages, and PDF reads reset
  positions between pages.
- Tool results distinguish execution state, phase and effects. English and Chinese
  prompts and interface labels reflect the new runtime contract.
- CI checks fixed commits and installs pinned Chromium before sandbox tests.
  Approval recovery and browser test cleanup wait for their outstanding operations.

### Upgrade

Stop active work and back up the complete data directory and database before
upgrading. Install matching Desktop and Server versions, then reconnect browsers.
The database advances to **schema 17** and tools to **schema 6**. Rollback requires
a matching backup; an older server must not open the migrated database.

`review_inbox` and `wait_for_message` have been replaced by `read_inbox` and
`review_progress`. Old argument aliases are not retained. Completed historical
tool receipts remain intact. Unstarted calls using the old contract are sealed
for replanning and their pending approvals are invalidated. Operations with
uncertain effects remain blocked for verification before continuation.

### Packages and verification

The release includes macOS Apple Silicon DMG/ZIP, Linux x64 DEB/AppImage, the
Linux x64 native server and a server container. The published `intrica-update.json`
and `SHA256SUMS` identify the complete asset inventory, checksums and image digest.
The release workflow verifies installers and installed applications before publication.

**macOS packages use ad-hoc signing and are not notarized by Apple.** Install
manually: quit Intrica, replace the app in Applications and reopen it. If macOS
blocks startup, use System Settings → Privacy & Security → Open Anyway.
The updater provides a manual download action for these packages.

See [installation](https://github.com/M0gician/intrica/blob/v0.5.0/README.md),
[self-hosting](https://github.com/M0gician/intrica/blob/v0.5.0/docs/self-hosting.md)
and [update/recovery](https://github.com/M0gician/intrica/blob/v0.5.0/docs/updating.md).
Controlled tests verify runtime behavior; real-model task-quality replay remains
unverified.

## 简体中文

本版改善长时间协作中的任务延续与故障恢复。桌面端与服务端版本统一为 **0.5.0**。

### 主要变化

- 原始指令独立于模型生成的上下文摘要保存。结构化摘要保留来源和检查点，过期的压缩结果不能覆盖较新的上下文。
- Agent 在等待或结束前检查剩余工作、消息处理情况和交付依据。使用 `read_inbox` 和 `review_progress` 替代原有信箱确认与等待流程，消息处理工具采用扁平参数。
- 模型请求共享持久化配额、公平排队、有限重试和冷却时间，成功响应可用于恢复。普通消息提醒在安全时机处理，不再中断正在进行的模型推理。
- 文件读取使用扁平参数和持久化游标，游标绑定会话及源文件版本。大 UTF-8 文件分段读取，PDF 换页时正确重置读取位置。
- 工具结果分别表达执行状态、阶段和实际影响，中英文提示及界面同步采用新协议。
- CI 固定检出受测提交，并在沙箱测试前安装指定 Chromium；审批恢复及浏览器测试清理会等待尚未完成的操作。

### 升级说明

升级前停止活动任务，完整备份数据目录及数据库。桌面端和服务端使用匹配版本，升级后重新连接浏览器。
数据库迁移至 **schema 17**，工具接口升级至 **schema 6**。回滚需恢复匹配备份，不要用旧服务端打开已迁移数据库。

`review_inbox` 和 `wait_for_message` 已由 `read_inbox` 和 `review_progress` 替代，不保留旧参数别名。
历史已完成工具回执保留；旧协议下尚未开始的调用会被封存以重新规划，对应待审批申请失效。
执行结果不确定的操作继续保持阻塞，需要核实实际影响后再继续。

发布产物包括 macOS Apple Silicon 和 Linux x64 桌面安装包、Linux x64 原生服务包及服务端容器。
`intrica-update.json` 与 `SHA256SUMS` 提供完整文件清单、校验值和镜像摘要；发布流程在公开下载前检查安装包和安装后的应用。

**macOS 使用临时签名，未经 Apple 公证，需要手动安装。** 请退出 Intrica，替换“应用程序”中的旧版后重新打开。
若 macOS 拦截启动，在“系统设置 → 隐私与安全性”中选择“仍要打开”。更新界面会提供手动下载入口。

安装与升级步骤见[中文说明](https://github.com/M0gician/intrica/blob/v0.5.0/README.zh-CN.md)、
[自托管](https://github.com/M0gician/intrica/blob/v0.5.0/docs/self-hosting.md)及[更新与恢复](https://github.com/M0gician/intrica/blob/v0.5.0/docs/updating.md)。
受控测试验证运行行为；真实模型完成任务的质量尚未通过回放验证。
