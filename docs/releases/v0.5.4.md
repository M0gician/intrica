# Intrica v0.5.4

## English

This release improves context compaction and evidence retrieval in long Agent
conversations. Desktop and Server are **0.5.4**.

### Changes

- Preserve the complete previous summary when building the next handoff. Archive
  readable source text with the checkpoint so Agents can search and read omitted
  evidence progressively through `read_context`.
- Add a bilingual **Working materials** panel to the conversation details. Open
  summaries and source pages on demand, without adding a canvas node for every
  compaction. Archive reads recheck the recorded access scope.
- Rebuild current message obligations and recent reading positions from durable
  records. Use `read_next` to continue a read; expired cursors provide a position
  for reopening the source with current permissions.
- Accept valid plain-text handoffs without rejecting prose prefixes or incidental
  JSON formatting. Incomplete, empty, oversized or tool-calling summaries receive
  precise diagnostics and at most one correction. Validation records and the
  correction budget survive process restarts.
- Preserve the checkpoint and completed tool receipts when compaction fails.
  Pause automatic inference until explicit continuation; unresolved external
  effects require verification before work can resume.
- Consolidate source preparation, summary rules and query validation. Remove
  redundant fallbacks and simulated tests while retaining production regressions
  and fault-injection coverage.

### Upgrade

This release migrates to database **schema 18** and tool **schema 7**. Stop active
work and back up the complete database and data directory before updating.
Update Desktop and any separately deployed Server, then reconnect clients.

Completed tool receipts are retained. Unstarted old-protocol calls and their
pending approvals are sealed for replanning; effects with unknown outcomes remain
blocked for verification. The obsolete pre-compaction memory switch is removed.
After resolving any uncertain outcomes, explicitly continue a paused conversation.
Historical text that was already lost is not reconstructed automatically. A code
downgrade does not reverse the database migration; recovery requires a matching
backup. See [updates and recovery](../updating.md).

**macOS uses ad-hoc signing and is not notarized by Apple.** Quit Intrica and
manually replace the app in Applications. If startup is blocked, use System
Settings → Privacy & Security → Open Anyway.

Downloads include macOS Apple Silicon DMG/ZIP, Linux x64 DEB/AppImage, the Linux
x64 native server and a server container. `intrica-update.json` and `SHA256SUMS`
provide the complete inventory, image digest and file checksums.

## 简体中文

本版本改进长 Agent 会话中的上下文整理和原始资料查询。桌面端与服务端版本统一为 **0.5.4**。

### 改进内容

- 生成新摘要时保留完整的旧摘要，并随会话检查点保存可读原文。Agent 可通过 `read_context` 搜索和逐段读取摘要中未保留的证据。
- 会话详情新增中英文“工作资料”面板，按需查看摘要和原文；每次整理不会自动新增画布节点。读取资料时重新检查归档所记录的权限范围。
- 从持久记录中恢复当前消息责任和最近阅读位置。通过 `read_next` 继续阅读；游标过期时提供重新定位的依据，并按当前权限读取。
- 摘要不再因为开头措辞或正文恰好采用 JSON 而被拒绝。对未完整返回、空白、过长或包含工具调用的摘要给出具体原因，最多进行一次纠正；纠正额度和校验记录在进程重启后保留。
- 整理失败时保留原检查点及已完成工具的回执，暂停自动推理，等待明确的继续指令。外部操作结果尚未确认时，须先核实再继续工作。
- 合并重复的来源处理、摘要规则和参数校验，删除冗余回退与模拟测试，保留生产流程回归和故障注入检查。

### 升级说明

本版本升级至数据库 **schema 18** 和工具 **schema 7**。升级前停止正在执行的工作，备份完整数据库和数据目录。更新桌面端以及单独部署的服务端，然后重新连接客户端。

已完成工具的回执会保留。尚未执行的旧协议调用及其待审批记录会被封存，后续按新工具重新规划；结果未知的外部操作仍需核实。旧的“整理前保存笔记”开关已移除。处理完未确认结果后，可向暂停的会话发送明确的继续指令。更新不会自动补回此前已经丢失的历史内容。回退代码不能撤销数据库迁移，恢复时须使用匹配的完整备份，详见[更新与恢复](../updating.md)。

**macOS 使用临时签名，未经 Apple 公证，需要手动安装。** 请退出 Intrica，替换“应用程序”中的旧版。若 macOS 拦截启动，在“系统设置 → 隐私与安全性”中选择“仍要打开”。

发布产物包含 macOS Apple Silicon 和 Linux x64 桌面安装包、Linux x64 原生服务包及服务端容器。完整文件清单、镜像摘要和文件校验值见 `intrica-update.json` 与 `SHA256SUMS`。
