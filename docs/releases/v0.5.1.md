# Intrica v0.5.1

## English

This patch fixes missing ripgrep in desktop packages and restores remote server
upgrades after updating the desktop client.
Desktop and Server are released together as **0.5.1**.

### Fixes

- Desktop packages include the ripgrep binary for their platform. File-content
  searches no longer fail with a missing-platform-dependency error or require a
  separately installed `rg`.
- Desktop and native-server package acceptance now require an Agent to search a
  real file and verify the matched evidence. Regression tests also cover Go method
  patterns with escaped parentheses and character classes.
- A completed installation saved by an older client no longer appears as success
  for the new client's target version or hides the upgrade action.
- Opening the installation panel and finishing an installation trigger a fresh
  remote check. Success requires an active, healthy service running the requested
  version. The current-version field displays the inspected version.
- An available upgrade is labeled **Upgrade and connect**, with matching Chinese
  text. Remote checks run outside active installation to avoid competing SSH operations.
- Regression tests cover persisted state across client upgrades, stale completion
  records, current-version verification and the bilingual installation flow.

### Upgrade

Install Desktop 0.5.1, then open **Settings → Servers**, choose **Update service**
from the remote server's menu and select **Upgrade and connect**. The client
selects Server 0.5.1 and preserves the existing service settings and credentials.
Stop active work and back up the database and complete data directory before upgrading.

Database **schema 17** and tool **schema 6** are unchanged from 0.5.0. Upgrading
from 0.4.0 or earlier includes the protocol and migration changes described in
the [0.5.0 release notes](https://github.com/M0gician/intrica/releases/tag/v0.5.0).
Rollback requires a matching backup; do not open a migrated database with an older server.

**macOS packages use ad-hoc signing and are not notarized by Apple.** Quit Intrica,
manually replace the app in Applications and reopen it. If macOS blocks startup,
use System Settings → Privacy & Security → Open Anyway.

The release includes macOS Apple Silicon DMG/ZIP, Linux x64 DEB/AppImage,
the Linux x64 native server and a server container. `intrica-update.json` and
`SHA256SUMS` provide the complete download inventory, checksums and image digest.
See [installation](https://github.com/M0gician/intrica/blob/v0.5.1/README.md)
and [update/recovery](https://github.com/M0gician/intrica/blob/v0.5.1/docs/updating.md).

## 简体中文

本补丁修复桌面安装包缺少 ripgrep，以及更新桌面客户端后无法升级远程服务的问题。桌面端与服务端版本统一为 **0.5.1**。

### 修复内容

- 桌面安装包包含当前平台的 ripgrep 可执行文件，修复搜索文件内容时提示缺少平台依赖的问题，无需额外安装 `rg`。
- 桌面端和原生服务端的安装包验收增加 Agent 实际搜索文件并核对匹配内容的检查；回归测试覆盖带转义括号和字符集的 Go 方法搜索。
- 旧客户端保存的安装完成记录不再被当作新版安装成功，也不会隐藏升级按钮。
- 打开安装面板以及安装结束后，重新检查远端服务。只有服务运行、健康检查通过且实际版本匹配，才显示成功；当前版本来自本次检查。
- 有新版可用时，明确显示“升级并连接”，并提供对应英文文案。远端检查避开正在执行的安装，防止 SSH 操作互相冲突。
- 补充跨客户端版本恢复、过期完成记录、实际版本核验和中英文安装流程的回归测试。

### 升级说明

先安装桌面端 0.5.1，再进入“设置 → 服务器”，从对应服务器的菜单中选择“更新服务”，点击“升级并连接”。
客户端自动选择服务端 0.5.1，并保留已有服务配置和凭据。升级前停止活动任务，完整备份数据库及数据目录。

数据库 **schema 17** 和工具 **schema 6** 与 0.5.0 相同。
从 0.4.0 或更早版本升级时，包含 [0.5.0 发布说明](https://github.com/M0gician/intrica/releases/tag/v0.5.0)中的协议及数据库迁移。
回滚需恢复匹配备份，不要用旧服务端打开已迁移数据库。

**macOS 使用临时签名，未经 Apple 公证，需要手动安装。** 请退出 Intrica，替换“应用程序”中的旧版后重新打开。
若 macOS 拦截启动，在“系统设置 → 隐私与安全性”中选择“仍要打开”。

发布产物包括 macOS Apple Silicon 和 Linux x64 桌面安装包、Linux x64 原生服务包及服务端容器。
完整文件清单、校验值和镜像摘要见 `intrica-update.json` 与 `SHA256SUMS`。
安装及升级步骤见[中文说明](https://github.com/M0gician/intrica/blob/v0.5.1/README.zh-CN.md)
和[更新与恢复](https://github.com/M0gician/intrica/blob/v0.5.1/docs/updating.md)。
